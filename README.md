# Burger's Equation with Stratonovich Noise

Résolution numérique simple de l'équation de Burgers 1D bruitée (différences finies + Euler-Maruyama), comparant les interprétations d'Itô et de Stratonovich pour un bruit multiplicatif.

Voir [`burgers_ito_stratonovich.ipynb`](burgers_ito_stratonovich.ipynb).

Un PINN (Physics-Informed Neural Network) simple pour la version déterministe se trouve dans [`pinn_burgers.ipynb`](pinn_burgers.ipynb).
